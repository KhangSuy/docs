# Báo cáo sự cố Windows

Mở index.html trong trình duyệt. Bản demo so sánh thời điểm của sự kiện trong hai nguồn log giả lập và xuất báo cáo JSON. Có tám phép thử trên mẫu chuẩn.

Thử đổi giờ dừng dịch vụ từ 21:02 sang 19:00 để xem một sự kiện nằm ngoài khoảng lỗi bị loại. Thử đổi token giả để so sánh nội dung báo cáo. Phần đọc log thô thật là bước phát triển tiếp theo.
